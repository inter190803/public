この構成を成立させる「3つの切り札（2026年公式仕様）」

  1. Copilot Cowork の「過去チャット引き継ぎ（Reference previous chats）」：定額の Copilot Chat で Work IQ を使って調査・議論・下書きを100%終わらせ、その会話スレッドを Cowork に直接引き継いで「ファイル生成・送信・調整」だけを実行できる（Microsoft Learn: Copilot Cowork overview）。
  2. 定額内 Researcher エージェントの「GPT × Claude マルチモデル Critique」：有償 M365 Copilot ライセンスに含まれる Researcher は、OpenAI モデルと Anthropic Claude モデルによる相互審査（Critique）に対応しており、追加クレジット0で Anthropic 品質の検証ループを回せる（Microsoft サポート / Microsoft Copilot Blog）。

4. ハーネス再現の核心：4ステップ「ゼロ消費仕込み → 1ショット実行」パイプライン

Cowork のクレジットは「①モデル、②読み込むコンテキスト量、③ツール呼び出し回数、④実行時間」の掛け算で膨張します（A Guide to Cloud）。したがって、「探索・試行錯誤・手戻り」をすべて Layer 1（0追加クレジット）で吸収し、Layer 2（Cowork）を純粋な「確定済み仕様のコンパイラ＆実行機」にするのが最強の設計です。

STEP 1 0 cr

文脈収集＆一次ドラフト

M365 Copilot Chat（Work IQ）または Researcher / Analyst で、社内のメール・Teams・会議議事録・Excelから必要情報を抽出し、構造化メモを作る。

出力：Copilot Pages / チャット履歴

STEP 2 0 cr

異種モデル監査＆仕様圧縮

Gemini Enterprise（M365コネクタ）で Step 1 の出力と一次資料を突き合わせ、論理の抜け・数値矛盾を監査（Critic）。Cowork に渡す1枚仕様書（Execution Brief）へ圧縮。

出力：_AI_Harness/specs/案.md

STEP 3（必要な時のみ） 125〜500 cr

Cowork 1ショット自律実行

過去チャット参照＋Custom Skill＋仕様書1枚だけを指定して Cowork を起動。複数Officeファイル生成・既存資料更新・Outlook/Teams展開を一気通貫で実行。

出力：完成PPT/Excel/Word・承認送信

STEP 4 0 cr

コスト検算＆スキル還流

Cowork 終了直後に /cost で消費クレジットを確認。うまくいった指示手順は Custom Skill や _AI_Harness/skills/ に昇格させ、次回のクレジット消費をさらに削減。

出力：実績ログ・改善版Skill

💡 8割の日常業務は「STEP 1 ＋ STEP 2」だけで完結させる

単発のメール返信、会議要約、議事録整理、1つのWord/Excelドラフト、方針の壁打ち、PowerShell/DAXコード作成などは STEP 3（Cowork）を踏まないのが鉄則です。アプリ内 Copilot と Gemini Enterprise の往復だけで十分高品質かつ 0追加クレジットで完了します。

🚀 残り2割の「ここぞ」で Cowork に集中投下する

「方針展開パッケージ一式（経営層向けPPT＋部門展開メール＋Teams告知＋説明会日程調整）」「複数Excelの横断突合と異常値レポート作成」「既存PowerPointの大幅改訂」など、人間がやると2〜4時間かかる複合実行にだけ Cowork を切ります。

# 監査観点（厳格にチェック）
1. 論理の飛躍・根拠なき断定・数値の整合性ミスがないか（M365上の一次資料と矛盾しないか）
2. 読み手（役員／部門長／現場）が即座に意思決定・行動できる具体性があるか
3. 冗長な表現や、Cowork実行時に不要な背景ノイズが混ざっていないか

1. **広域検索の禁止**: ユーザーが明示したファイル・過去チャットスレッド以外の Work IQ 検索は行わない。情報が不足している場合は推測で検索を広げず、即座に停止してユーザーへ確認する。
2. **思考ループの最小化**: 構成の作り直しや複数案の比較生成は行わず、指定された Execution Brief の構成を忠実に1回でビルドする。
3. **承認ゲート**: メール送信・Teams投稿・会議招待の実行前は必ずドラフト提示と明示的承認を求める。
4. **出力先固定**: 生成ファイルは指定された OneDrive / SharePoint フォルダ（既定: _AI_Harness/03_outputs/）へ保存する。

8. 2万クレジットを溶かさないための「5大NG行為」と回避策

NG①：Cowork のスケジュール実行・イベント駆動を常用する

「毎朝8時にDaily Briefingを自動生成」「特定メール受信時に自動要約」を Cowork で組むと、1回150〜300cr × 20営業日 ＝ 単体で月3,000〜6,000crが自動消滅します。定期通知は Power Automate ＋ 定額 Copilot Chat の手動プロンプトに逃がしてください（Zation: Microsoft token economics）。

NG②：Cowork に「ふわっとした調査・壁打ち」を投げる

「最近の部門課題をメールとTeamsから調べて提案書にして」と丸投げすると、Cowork が Work IQ を広域検索し、複数ツールを反復呼び出しして一発で Heavy（1,200〜2,000+ cr） に跳ね上がります。必ず定額の Copilot Chat / Researcher で事実を絞り込んでから渡してください。

NG③：常に最上位モデル（Opus 固定）で Cowork を回す

Microsoft の公式分析でも、全ステップを最上位モデル高推論で回すのが最も高コストと明示されています（Microsoft Copilot Blog: What AI at work really costs）。基本は Auto ルーティング（または Sonnet 4.6 / 低コスト特化の Cowork 1）を使い、Opus 級は経営判断の最終仕上げに限定してください。

NG④：M365 と Gemini Enterprise 間で同じ機密データを無秩序にコピペする

両環境ともエンタープライズデータ保護（EDP / ネイティブ権限尊重）を備えていますが、ローカルPCへ機密ファイルを大量ダウンロードして手動転記すると統制が崩れます。必ず M365 コネクタ経由で SharePoint / OneDrive の権限境界内を参照させてください。

NG⑤：`/cost` を見ずに月末にクレジット枯渇を知る

Cowork のタスク完了直後に /cost を打つ習慣をつけるだけで、「どの指示がクレジットを食うか」の体感精度が1週間で劇的に上がります。週次で 5,000 cr（月2万の25%）をペースメーカー上限に設定するのが安全です。
