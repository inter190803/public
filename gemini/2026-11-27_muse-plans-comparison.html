Meta Muse の有料化は「枠の拡大」より「Muse Wonder への切替」が最大の分岐点

Meta のパーソナル AI エージェント「Muse」における Free / Power（月 $20）/ Maximum（月 $100）の 3 プランを、一次情報と第三者ベンチマークから整理した比較資料です。定期実行や自律タスクを多用する利用者が課金価値を見極めるための判断材料をまとめています。

調査基準日: 2026年11月27日 ／ 一次情報（Meta 公式ヘルプ・公式ブログ・製品ページ）を優先し、未公開項目および二次情報は明示的に区別して記載しています。

要点：まずは Power（$20/月）のモデル向上価値を見極め、Maximum は枠不足を実測してから検討するのが合理的

Muse 本体の有料プランは Power（$20/月・週 5 億トークン） と Maximum（$100/月・週 30 億トークン） の 2 層です。無料プラン（Free）でも基本機能や Muse Mail は利用できますが、週次上限の具体的トークン数と無料比倍率は公式に未公開です。

有料化の最大の価値は、メイン会話・成果物生成・定期実行・バックグラウンド作業を担うモデルが Muse Spark 1.3 から上位の Muse Wonder へ切り替わる点 にあります。第三者ベンチマークではエージェント端末作業（Terminal-Bench 4.0）が 33% → 52% へ大きく伸び、ハルシネーション率も 33% → 27% へ低下しています。一方、Power と Maximum の公式な差は主に「週次トークン枠（6 倍）」と「1 日通話上限（2 倍）」であり、モデル差は公式に確認されていません。

料金体系は月額固定の米ドル基準、年払い・無料トライアルは公式未確認

Meta の日本語版公式ヘルプ「Museサブスクリプションについて」でも、料金は Power プラン（$20/月） および Maximum プラン（$100/月） と米ドルのみで表記されており、公式の日本円定価は記載されていません。請求は最初の購入日と同じ日に毎月自動更新される仕組みで、年払いプランや年払い割引の存在は公式情報では確認できませんでした（二次情報の調査記事 Superapp でも年払いなしとされています）。

また、有料プランに対する常設の無料トライアル期間・条件についても、公式ヘルプ上に記載は確認できませんでした。なお、公式ヘルプ冒頭には「特典と提供状況は地域やアカウントによって異なり、登録前のオンボーディング画面に表示される」と注記されており、日本から iOS / Android アプリ内課金で登録する場合はストア側の為替・手数料が反映された円額が提示される点に留意が必要です（二次情報では Power が 2,799〜3,499 円、Maximum が 16,990 円前後と報じられています）。

見落としやすい選択肢として、Meta はサブスクリプションとは別に「追加の Muse トークン」の 1 回限り買い切り購入を公式に用意しています（How to buy additional Muse tokens）。無料プランのままでも購入でき、週次枠と違って有効期限がなく（never expire）、サブスクリプションを解約しても使い切るまで残ります。ただし返金・換金・他アカウント譲渡は不可です。

使用量は「週次トークン枠＋日次通話上限」で管理、無料枠の実数は非公開

Muse 本体の使用量は、Muse Code のような「5 時間ごとのプロンプト枠」ではなく、週単位の Muse トークン上限（Weekly usage allowance） と 1 日あたりの通話発信回数 で管理されます。週次枠の未消化分は翌週へ繰り越されません（does not rollover）。

無料プラン比の倍率は公式非公開

Meta 公式ヘルプは Free プランについて「使用制限付きで無料（available for free with a usage limit）」と記すのみで、具体的なトークン数や有料プランとの倍率を公表していません。一部二次情報（The AI Corner）では約 1 億トークン/週との言及もありますが、公式ドキュメント上は未確認です。

リセット曜日・時刻も公式未明記

無料枠・有料枠ともに週単位でリセットされますが、具体的なリセット曜日や時刻は公式ヘルプに記載がありません（二次解説 LimitWatch でも同様に非公開と確認）。アプリや Web の設定画面（Settings）から残量を確認する運用になります。

タスク種別とモデルで消費量は変動

公式 FAQ は「消費される Muse トークン量は、機能・要求の複雑さ・入出力サイズ・モデル階層 によって変動する」と明記しています。ブラウザ操作やファイル生成、さらに上位モデル Muse Wonder の稼働時は、短いチャットより多くの枠を消費します。

Muse Spark 1.3 から Muse Wonder へ：エージェント実務と正確性が大幅に向上

Meta の 2026 年 10 月 12 日の公式発表（Muse Wonder 公式ブログ）では、Muse 系列のモデルは Muse Spark（現行 1.3）、Muse Wonder、最上位の Muse Wonder Full の 3 階層で構成されます。同ブログは、Muse Wonder が Muse アプリ内の体験を駆動し、まずサブスクリプション加入者から展開されること、さらに成果物生成（artifact generation）や高度な知能を要する処理を担うことを明記しています。

有料プランでは、メインの会話・成果物作成・定期実行・サブエージェント・バックグラウンド作業を Muse Wonder が担う一方、最上位の Muse Wonder Full は別製品「Muse Code」の上位プラン限定であり、Muse 本体の Power / Maximum では利用できません。

公式発表ベンチマークと第三者実測の照合

Artificial Analysis の第三者レポート で公表された数値は、Intelligence Index（48 / 52 / 56）、Terminal-Bench 4.0（33% → 52%）、AutomationBench-AA（58% → 68%）、ハルシネーション率（33% → 27%）のいずれも完全に一致しています。一方、Meta の公式モデルカード（公式ブログ およびモデルカード集計 DEV Community）では、独自の長文脈記憶評価（MemoryBench）や目標完遂評価（FocusBench）、長時間コーディング（SWE-Marathon）での優位が強調されています。

トークン消費の隠れた注意点：Artificial Analysis の計測では、Muse Wonder（max）は Spark 1.3 より出力トークンが約 10% 少ない（54k vs 60k）一方、入力トークンは 28% 多い（7.69M vs 6.03M） 結果となりました。API 単価も入力 $4 / 出力 $20（Spark 1.3 は $1.25 / $4.25）と高コスト構造のため、有料プラン移行後に同じ定期ジョブを回しても、トークン消費ペース自体は Spark 時代より増える可能性があります。

機能差は限定的：Muse Mail は無料でも利用可、Home Link は米国限定

Muse 本体のプラン設計は「機能のロック解除」よりも「上位モデル（Wonder）と週次容量の拡張」が中心です。チャット・スペース・コネクター連携・定期実行・仮想マシン（VM）・ブラウザ操作（内蔵ブラウザおよび Muse Chrome Extension）といった中核機能は、無料プランから利用できます（ToolColumn）。

Muse Mail（@muse.ai 専用メール）

エージェント専用の @muse.ai アドレスを発行し、メール転送や外部との連絡を任せられる機能です。Meta 公式ヘルプ「About Muse email addresses」に有料プラン限定との記載はなく、送信回数制限（Sending limits）はあるものの誰でも設定できます。二次情報（Muse Lab 等）でも、2026年11月20日頃から無料プランでも専用アドレスを作成可能になったことが確認されています。

Muse Home Link（スマートホーム連携機器）

自宅 Wi-Fi に接続して家電やローカル HTTP API 機器を操作できる USB-C デバイス（ESP32-C5 搭載）です。公式ページ「Muse Home Link」には 「Included with an active Muse subscription in the United States only, limit one per subscriber（米国の有効な Muse サブスク加入者限定で 1 人 1 台付属）」 と明記されており、日本在住ユーザーは特典対象外 です（オープンソースの ESP32 Device SDK を用いた自作は技術的に可能）。

電話発信機能（Phone calls）

公式ヘルプでプラン差が明確に数値化されている数少ない機能差です。Power は 1 日 10 回、Maximum は 1 日 20 回 の通話発信上限が設定されています（Free には回数表記なし）。ただし、通話機能を含む一部特典は地域・アカウントごとに提供状況が異なります。

優先処理・新機能への早期アクセス

Muse 本体の Power / Maximum プランについて、処理の優先キューや新機能への早期アクセス（Early access）を保証する公式記載は確認できませんでした。なお、「Early access to new features」が公式に明記されているのは、次節で述べる別製品 Muse Code の Power Usage（$50/月）以上のプランです。

Muse 本体と Muse Code は別製品：Wonder Full を使うには Muse Code 契約が必要

名前が似ていて混同されやすい「Muse Code」は、Meta の開発者向け CLI コーディングエージェント（dev.meta.ai/products/muse-code）であり、パーソナル AI エージェント「Muse」とはアカウント課金・プラン体系・上限管理のすべてが別系統です。Muse 本体の Maximum（$100/月）を契約しても、Muse Code や最上位モデル Muse Wonder Full は利用できません。

ヘビーユーザー向けの判断材料：どのプランがどんな利用状況に合うか

定期実行ジョブ（健康チェック・週次レポート・監視など）と自律的な目標管理を多数稼働させ、無料枠を週の途中で約 38% 消費している利用者を前提に、3 つの選択肢の判断材料を整理します。結論を断定せず、重視する軸に応じた見極めポイントを提示します。

Free 継続（＋必要時に買い切り追加トークン）が合うケース

  • 週途中で 38% 消費のペースであれば、1 週間トータルでは 70〜80% 前後に収まる見込みであり、「枠が足りずに止まる」問題だけで見れば Free 継続でも回る可能性が高い。
  • 現在の Muse Spark 1.3 の出力品質・定期実行の成功率・自律判断の精度に大きな不満がない。
  • 突発的な重い調査で枠を超えた週だけ、無期限の買い切り追加トークンでスポット補填する方が月額固定費を抑えられる。

Power（$20/月）への課金価値が出やすいケース

  • 「モデルの賢さの伸び」を重視する場合：定期実行・監視・自律目標管理は、Terminal-Bench（33%→52%）や AutomationBench（58%→68%）、ハルシネーション率改善（33%→27%）、Active Memory 強化の恩恵を最も受けやすい領域。
  • 手戻りや誤報告が減ることで、エージェントの監督コスト自体を下げたい。
  • 今後ジョブ数やブラウザ操作・成果物生成を増やす予定があり、週 5 億トークンの明示的な余裕を確保したい。

Maximum（$100/月）を検討すべきケース

  • Power との公式差は「週次トークン 6 倍（30 億）」「1 日通話 2 倍（20 回）」であり、モデル性能の差は公式確認されていない。
  • したがって、最初から Maximum を選ぶ根拠は薄い。まず Power で 1〜2 週間運用し、Wonder 稼働に伴うトークン消費増を含めて週 5 億トークンを恒常的に超過すると実測できた場合にアップグレードするのが合理的。
  • なお、日本在住では Muse Home Link 特典が対象外のため、ハードウェア特典を課金理由に含めない判断が必要。
