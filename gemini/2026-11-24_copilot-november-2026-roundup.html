2026年11月のCopilotは「チャット」から「常駐・統制・従量課金」へ移行した

2026年11月1日〜24日の発表（主軸は11月17〜20日の Microsoft Ignite 2026）により、Microsoft 365 Copilot は「質問に答える補助ツール」から「自律稼働する業務エージェント基盤（仕事のOS）」へと再定義されました。同時に、Agent 365 によるマルチプラットフォーム統制・FinOps 可視化、そして12月〜2027年初頭に向けたライセンス・従量課金制度の転換が確定しています。

1. 今月のハイライト（最重要発表 5選）

11月発表で完成した企業Copilotの4層構造
① 入口・日常業務
Home / Office in Copilot（GA）＋ Auto ルーティング
② 自律・常駐実行
Cowork（GA）＋ Autopilot（Frontier）＋ Code
③ 統制・ID管理
Agent 365 ＋ Entra Agent ID ＋ MXC 端末隔離
④ 予算・ROI管理
Copilot Credits 上限 ＋ Business Analytics
  1. [事実]11月17日：M365 Copilot の新基盤が一斉展開 — Chat と Cowork を統合する Home、アプリ内で Word/Excel/PowerPoint を完結編集できる Office in Copilot、および Copilot Managed Runtime が一般提供（GA）となりました（Microsoft Copilot Blog）。
  2. [事実]11月17日：常駐エージェント Copilot Autopilot が Frontier 展開開始 — 固有の Microsoft Entra Agent ID とメモリを持ち、Teams や Outlook 上で継続稼働する個人向け自律エージェントが Frontier 顧客向けに提供開始されました（explainx.ai解説）。
  3. [事実]11月17日：Agent 365 がマルチプラットフォーム統制と AI FinOps へ拡張 — Salesforce・Google Vertex AI・Anthropic・OpenAI 等の外部エージェントにも Entra Agent ID を付与可能になり、ROI を業務時間換算で可視化する Agent 365 Business Analytics（Frontier Preview）が発表されました（Agent 365 Blog）。
  4. [事実]11月2日・3日・19日：無償 Copilot Chat の利用上限導入と課金移行の調整 — 未ライセンスユーザー向け Copilot Chat に日次変動型のフェアユース上限が導入されたほか、新規 Copilot Business の従量課金デフォルト有効化は 2027年1〜3月期へ延期されました（Partner Center 11月発表）。
  5. [事実]11月16〜18日：GitHub Copilot の新モデル群投入と VS Code Local ハーネス廃止予告 — MAI Code 2 / Flash、GPT-6.2 Astra / Sol、Gemini 4 Neon などが相次いで追加され、GitHub Copilot 活動の Agent 365 連携や、VS Code Local ハーネスの 2027年2月廃止が公表されました（GitHub Changelog）。

2-2. Microsoft Copilot Autopilot（提供状況・機能・ガバナンス）

名称混同に注意：Windows Autopilot とは別製品

[事実] PC 初期展開の「Windows Autopilot」とは異なり、Microsoft Copilot Autopilot は Microsoft クラウド上で24時間稼働し、Teams・Outlook・ドキュメント内で同僚のように @メンションできる個人向け自律エージェントです（2026-11-17 Frontier ロールアウト開始）。

主な機能と初期学習（Orientation）
  • [事実] チャネル監視、メールフォローアップ、定例業務、サプライヤーレビュー進行などをプロンプト待ちなしで自律実行。
  • [事実] 有効化直後は過去約30日分のアクセス可能なメール・会議・チャット・ファイルを読み取り専用で学習し、初日の誤送信を防止（explainx.ai）。
ガバナンス・利用条件・未公開事項
  • [事実] 各 Autopilot に固有の Entra Agent ID と人間の管理責任者（Manager）を紐づけ、監査ログ分離・即時停止・重要操作前承認を設定可能（Agent 365 Blog）。
  • [事実] Frontier 参加＋M365 Copilot ライセンス＋Copilot Credits 従量課金ポリシーが必須。1ユーザーあたり同時稼働上限や越境レジデンシ細則は11/17時点で未公表。

2-3. Copilot Studio / Agent 365 / Entra Agent ID

[事実] 2026年11月17日の Ignite 発表で、Agent 365 は Microsoft 製以外のサードパーティ基盤や社員端末上のローカルエージェントまで含めた「全社AI統合コントロールプレーン」へ拡張されました（Agent 365 Blog）。

ID 連携の外部拡大

Amazon Bedrock に続き Salesforce Agentforce、Google Vertex AI、Databricks、Snowflake、Anthropic、OpenAI、ServiceNow 等へ Entra Agent ID を自動付与（12月完了予定）。シークレットレス認証も導入。

シャドーAI・端末隔離

Defender（GA）＋ Global Secure Access（Preview）が60種超のローカルエージェント（Claude Code、GitHub Copilot CLI 等）と MCP 接続を検知。Windows の MXC コンテナでファイル/通信境界を強制。

FinOps・ROI 可視化

Tools Registry が GA。M365 サブスク保有者へ Agent 365 基本利用分析を GA 開放したほか、業務時間・金額換算で ROI を示す Business Analytics（Frontier）を発表。

Copilot Studio・マルチテナント・Purview DLP の詳細を見る
  • Copilot Studio 移行（11/17 Learn 更新）：レガシーなサービスプリンシパル利用エージェントから Entra Agent ID への移行および削除連動（Studio 削除で Entra ID も自動削除）が整理（Microsoft Learn）。
  • マルチテナント管理（Public Preview）：GDAP 経由で複数顧客テナント・子会社テナントのエージェント構成比較、一括承認/ブロック、AI コスト管理が可能（Partner Center）。
  • Purview DLP for AI（Preview）：Microsoft エージェントに加え Claude Code / Desktop、GitHub Copilot CLI / App / VS Code 拡張に対する機密情報送信ブロックに対応。

3. 管理面の注意点（セキュリティ・ガバナンス・予算暴走防止）

予算統制上の最重要仕様（2点）

[事実] ①同一ユーザーに複数の従量課金ポリシーが適用された場合、最も制限が緩いルール（least-restrictive）が優先されます。②一度有効化した従量課金は完全オフに戻せず、上限を 0 に設定して停止する仕様であり、既定で「Auto-apply new services」がオンになります（Deployment Labs）。

  • [事実] 無償 Copilot Chat 上限からの勝手購入リスク：フェアユース上限到達時にライセンス申請・購入ボタンが出るため、セルフサービス購入を無効化していないテナントでは意図しない課金増が発生し得ます。
  • [事実] ローカルAI／シャドーAI のデータ流出対策：端末上の Claude Code や GitHub Copilot CLI に対し、Defender のローカル保護（GA）と Purview DLP（Preview）の併用が現実的な統制線となります。
  • [推測] Purview Data Governance 終了との混同注意：11月12日に Purview Data Governance の2027年11月サポート終了（Fabric OneLake 移行）が発表されましたが、エージェント保護を担う Purview Data Security / Compliance（DLP 等）は継続するため切り分けて扱う必要があります（Partner Center）。
