2026年11月のCopilotは「チャット」から「常駐・統制・従量課金」へ移行した

対象期間: 2026年11月1日〜24日（公開情報のみで構成）。2026年11月17〜20日の Microsoft Ignite 2026 を軸に、M365 Copilot の「仕事のOS」化、Copilot Autopilot の Frontier 展開、Agent 365 による統制と FinOps、さらに2026年12月〜2027年初頭のライセンス・課金制度転換が出揃いました。

2026-11-17

2026-12-01
M365 ベースライセンス不要の新オファー開始（旧アドオンはパートナー経由で新規販売終了）

Cowork・Autopilot・Code 等の高度 AI 課金単価（新規 Business の自動有効化は 2027 Q1 へ延期）

1. 今月のハイライト：押さえるべき5つの転換点

今月の発表は単発の機能追加にとどまらず、Microsoft が Copilot を「質問に答える補助ツール」から「自律稼働する業務エージェント基盤」と「課金・統制の仕組み」へ再定義した点に本質があります。

  1. [事実]11月17日：M365 Copilot の新基盤が一斉展開 — Chat と Cowork を統合する Home、アプリ内で Word/Excel/PowerPoint を完結編集できる Office in Copilot、および Copilot Managed Runtime が一般提供（GA）となりました（Microsoft Copilot Blog）。
  2. [事実]11月17日：常駐エージェント Copilot Autopilot が Frontier 展開開始 — 固有の Microsoft Entra Agent ID とメモリを持ち、Teams や Outlook 上で継続稼働する個人向け自律エージェントが Frontier 顧客向けに提供開始されました（explainx.ai解説 / Microsoft公式）。
  3. [事実]11月17日：Agent 365 がマルチプラットフォーム統制と AI FinOps へ拡張 — Salesforce・Google Vertex AI・Anthropic・OpenAI 等の外部エージェントにも Entra Agent ID を付与可能になり、ROI を業務時間換算で可視化する Agent 365 Business Analytics（Frontier Preview）が発表されました（Agent 365 Blog）。
  4. [事実]11月2日・3日・19日：無償 Copilot Chat の利用上限導入と課金移行の調整 — 未ライセンスユーザー向け Copilot Chat に日次変動型のフェアユース上限が導入されたほか、新規 Copilot Business の従量課金デフォルト有効化は 2027年1〜3月期へ延期されました（Partner Center 11月発表 / Deployment Labs整理）。
  5. [事実]11月16〜18日：GitHub Copilot の新モデル群投入と VS Code Local ハーネス廃止予告 — MAI Code 2 / Flash、GPT-6.2 Astra / Sol、Gemini 4 Neon などが相次いで追加され、GitHub Copilot 活動の Agent 365 連携や、VS Code Local ハーネスの 2027年2月廃止が公表されました（GitHub Changelog）。

2. テーマ別まとめ（2026年11月発表分）

2-1. Microsoft 365 Copilot（新機能・Frontier・モデル動向）

  • [事実]2026年11月17日｜Home と Office in Copilot が GA：Chat と Cowork の統合起点となる「Home」および、Copilot アプリ内で Word・Excel・PowerPoint を共同編集できる「Office in Copilot」が一般提供されました。なお Home・Code・Autopilot の構想自体は2026年9月25日の発表が起点です（Microsoft Copilot Blog / 9月発表背景）。
  • [事実]2026年11月17日｜Today（Private Preview）と Workspaces（Frontier）：メール・予定表・Teams から要対応事項と下書きを自動提示する「Today」がプライベートプレビュー開始。人とエージェントが共同編集する「Workspaces」（Copilot Notebooks の進化版）は Frontier 向けに提供開始されました（Microsoft Copilot Blog）。
  • [事実]2026年11月17日｜Copilot Code と Managed Runtime：自然言語でアプリ・ダッシュボードを構築する「Copilot Code」は数週間以内の GA 予定、企業テナント内で安全にホスト・管理する「Copilot Managed Runtime」は同日 GA となりました（Microsoft Copilot Blog）。
  • [事実]2026年11月17日｜フロンティアモデル統合と Auto ルーティング強化：Cowork / Copilot のマルチモデル基盤へ GPT-6.2 Astra / Sol、Claude Fable 5.2、Claude Opus・GPT-6.1 Sol 向け Fast mode が追加。Microsoft-Decision-1.1（同日 GA）を用いた Auto が推論深度の自動調整とサブエージェント並列実行（Frontier）を担います（Copilot Cowork Blog / Microsoft Source）。
  • [事実]2026年11月5日・17日｜EU Data Boundary と業務プラグイン拡充：11月5日に Claude モデルの EU Data Boundary 対応を発表。11月17日には Dynamics 365（100超スキル）、Salesforce in Copilot（38超セールススキル、Preview）、財務（30スキル）、法務（20超スキル）、Edge for Business 上の Cowork（GA）が公開されました（Microsoft Copilot Blog / Cowork Blog）。

2-2. Microsoft Copilot Autopilot（提供状況・機能・ガバナンス・課金）

  • [事実]2026年11月17日｜Frontier 顧客向けにロールアウト開始：PC 初期設定の「Windows Autopilot」とは別物であり、Microsoft クラウド上で常時稼働する個人向け自律エージェントです。Teams・Outlook・ドキュメント内で @メンションして協働でき、サプライヤーレビューの進行管理などを自律実行します（Microsoft Copilot Blog / explainx.ai）。
  • [事実]初期オンボーディング（Orientation window）と権限境界：有効化直後は過去約30日分のアクセス可能なメール・会議・チャット・ファイルを読み取り専用で学習し、誤送信を防止します。各 Autopilot に専用の Microsoft Entra Agent ID と管理責任者（Manager）が割り当てられ、監査ログ分離・即時停止が可能です（explainx.ai / Agent 365 Blog）。
  • [事実]利用条件と課金：利用には Frontier プログラム参加、M365 Copilot ライセンス、および Copilot Credits による従量課金ポリシーの有効化が必要です。なお1ユーザーあたりの同時作成上限や越境データレジデンシ細則は11月17日時点で未公開です（explainx.ai / Deployment Labs）。

2-3. Copilot Studio / Agent 365 / Entra Agent ID

  • [事実]2026年11月17日｜Entra Agent ID の非Microsoft基盤拡大と Autopilot 対応：Agent 365（2026年5月提供開始、登録5,000万エージェント突破）が強化され、Amazon Bedrock に続き Salesforce Agentforce、Google Vertex AI、Databricks、Snowflake、Anthropic Claude Managed Agents、OpenAI、ServiceNow 等へ Entra Agent ID 付与を拡大（12月完了予定）。Copilot Autopilot およびローカルエージェント（GitHub Copilot CLI、Claude Code）への ID 付与もプレビュー開始しました（Agent 365 Blog）。
  • [事実]2026年11月17日｜ローカル／シャドーAI検知と Windows 隔離：Microsoft Defender（GA）と Entra Global Secure Access（Preview）が端末上の60種超のローカルAIエージェント（Claude Code、GitHub Copilot CLI 等）と MCP サーバー接続を検知。Windows 上の Microsoft Execution Containers（MXC） と Intune ポリシーによりファイル・ネットワーク境界を OS レベルで強制します（Agent 365 Blog）。
  • [事実]2026年11月17日｜Tools Registry・動的リスク・Business Analytics：MCP サーバーやプラグイン依存関係を可視化する Tools Registry が GA（Azure AI Gateway / LiteLLM 連携は Preview）。さらに動的エージェントリスク評価（Preview）、マルチテナント管理（Public Preview）、M365 サブスク保有者向け Agent 365 基本利用分析の開放（GA）、および投資対効果を時間・金額換算する Agent 365 Business Analytics（Frontier）が発表されました（Agent 365 Blog）。
  • [事実]2026年11月17日｜Copilot Studio の Entra Agent ID 移行ドキュメント更新：レガシーなサービスプリンシパル利用エージェントから Entra Agent ID への移行・削除連動（Studio 側削除で Entra ID も自動削除）が整理されました（Microsoft Learn）。

3. 管理面の注意点：セキュリティ・ガバナンス・予算暴走防止

今月のアップデートでは利便性と引き換えに「自律エージェントの権限境界」と「従量課金の青天井化」という2つの管理リスクが顕在化しています。

「複数ポリシーが重複した場合は最も制限が緩いルールが優先される」「一度構成した従量課金は完全オフに戻せず上限0で止める」——課金設計の罠に要注意。
  • [事実]従量課金ポリシーの挙動：Partner Center 仕様上、同一ユーザーに複数ポリシーが当たると最も緩い制限（least-restrictive）が勝ちます。また「Auto-apply new services」が既定オンのため、新規課金サービスが自動編入される点に注意が必要です（Deployment Labs）。
  • [事実]Copilot Chat 上限からの勝手購入リスク：無償 Chat のフェアユース上限に到達したユーザーへライセンス申請・購入ボタンが表示されるため、セルフサービス購入を無効化していないテナントでは予期せぬ課金が発生し得ます（Deployment Labs）。
  • [事実]シャドーAI・ローカルエージェントの可視化と DLP：端末上の Claude Code や GitHub Copilot CLI などが業務データを持ち出すリスクに対し、Defender のローカルエージェント保護（GA）と Purview DLP（Preview）の組み合わせが現実的な統制手段となりました（Agent 365 Blog）。
  • [推測]Purview Data Governance 終了発表との切り分け：11月12日に Purview Data Governance の2027年11月サポート終了と Microsoft Fabric OneLake カタログへの移行が発表されましたが、エージェント保護を担う Purview Data Security / Compliance（DLP 等）は継続提供されるため混同しない整理が必要です（Partner Center 11月発表）。

  • [推測]Copilot Autopilot の全社展開：Frontier 展開が始まった段階であり、同時稼働上限や越境データレジデンシ細則が未公表のため、まずは1〜2業務での限定パイロットと承認ルール検証に留めるのが妥当（explainx.ai）。
